# ★2 中岩A・B デザイン確認用 v1

予定価格: 各80pt。未登録・未実装。生成方式: built-in image_gen。

## デザイン

- A: 横長で低い段差岩。丸みのある肩、浅い割れ目、緩やかなテラス。
- B: 片側に高さがある非対称の岩。上部の隆起と下方へ続く割れ目。
- 小岩の拡大素材ではなく、新規の形状。小岩より大きく、泳ぐ空間を残す配置を想定。
- 背景別に同じデザインを参照し、色・反射光・岩肌の見え方を調整。
- 岩に海藻は含めない。Aの低い肩やBの斜面の手前へ海藻を重ねる構成を想定。

## 6パターン

各画像内の左下は手前、右上は奥の同じデザイン。奥は小さく・少し薄くした見え方の仮合成。
アプリのdepth係数を実行したスクリーンショットではなく、デザイン・接地・背景との相性の確認用。
